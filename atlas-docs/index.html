What's New

What's New in v2026.05

  • 3 institution tiers — Academic (INST-ACAD, $399/mo: Research Hub · Grants · Thesis), Health System (INST-HLTH, $599/mo: Care Gap Monitor · MTM Billing · Command Center), and AMC (INST-AMC, $799/mo: all features). Superadmin "View As" panel now shows three institution buttons.
  • 3 instruments — MMAS-8 (public screening), MAP (institutional cross-sectional, 8-item), PEACS (longitudinal 22-item: BASE / MVMT / STRATA)
  • Clinical Study Module — Site Activation Tracker and IRB Submission Assistant for funded PIs
  • Patient Portal — patients can view their own score history
  • ZOE Remote Mode — SMS-delivered independent assessment without clinic attendance
  • Multilingual UI — interface available in EN / ES / FR / DE / PT; consent, labels, and results all update automatically
  • Benchmark comparison — every result screen shows the published literature mean (Morisky et al., 2008) and current ATLAS global dataset mean alongside the patient's score
  • Annual State of Global Adherence Report — institution-tier aggregated population health publication
  • Cartographic design language — PE Triangle visualisation for Architecture · Execution · Context domain profiles
  • SDoH Intelligence System — Three automated inference engines pre-fill up to 22 PEACS questions from MAP responses, intake social support data, and OpenStreetMap geo-scoring (pharmacy/healthcare density from home postal code). Patient burden reduced by up to 60%.
  • Home Postal Code Field — Optional field in MAP intake form. Geocoded client-side via Nominatim; never stored to server. Enables geo-inference regardless of clinic vs. home setting.
  • Verified POI Network — Crowd-sourced infrastructure map. Authenticated users contribute pharmacies, hospitals, clinics, transport, food banks, and community centers. Two confirmations required for verification. Verified POIs appear on the SDoH Globe and feed PEACS geo-scoring.
  • Cinematic Globe — Now stays still unless a new assessment is submitted in real-time; globe flies to each new submission location as it arrives.

Explorer · No key required
Explorer Mode

No workspace key, no registration. Click Explorer on the ATLAS entry screen for instant access to the full MMAS-8 + PEACS experience. Your data contributes to the global pool — not a private cohort. Use this to trial the platform before requesting a key, or for anonymous public collection. Use Start New Patient Session in the Explorer dashboard exactly as you would in a keyed workspace.
