What's New

What's New in v2026.06.15 — TESSERA Pharmacy Gateway

  • ATLAS Pharmacy Gateway v2 — Standalone 4-screen tablet app (pharmacy.html) for community pharmacists. Administers the full 8-item MAP instrument at the pharmacy counter. 5 languages (EN/IT/ES/FR/AR), 72px touch targets, ~3 minute administration time. Deployed via QR-linked URL with site code (e.g. pharmacy.html?site=PH-ROM-001). Now includes Screen 5 site dashboard with real-time risk distribution, domain mean scores, and PEACS phenotype breakdown.
  • FOFI Report Generation — Pharmacy dashboard (Screen 5) now has a "Generate FOFI Report" button. Produces a plain-text adherence report in FOFI/Order of Pharmacists format: summary, domain analysis, condition breakdown, PEACS phenotype distribution, clinical interpretation, and alert rate. Downloads as .txt file. Works in both live and demo modes.
  • Pharmacy Demo Mode — Append ?demo=true to pharmacy.html URL (pharmacy.html?demo=true) to load 68 synthetic Rome pilot records. No Firebase reads or writes in demo mode. Immediate "View Dashboard (68 Sample Patients)" button on the setup screen bypasses the question flow. Ideal for stakeholder demonstrations. FOFI report also generates from demo data.
  • Dual-Write Architecture — All three standalone apps (pharmacy.html, patient-map.html, chw.html) now write to two Firebase paths simultaneously: the silo path (pharmacy_assessments/, patient_self_assessments/, chw_assessments/) for per-site dashboards, and the main assessments/ path for the PI workspace count, global MAP globe, and longitudinal tracking. Pharmacy records include lat/lon coordinates (Rome: 41.9028, 12.4964) so they appear on the Mapbox MAP globe.
  • MAP Instrument — Validated Questions — All three standalone apps (pharmacy.html, patient-map.html, chw.html) and the map-assessment.js module now use the correct validated MAP instrument questions. Q1 (Execution), Q2–Q3 (Architecture, 14-day rolling anchor), Q4 (Context-Guard), Q5 (Execution, "last dose as directed"), Q6 (Architecture), Q7 (Context-Guard), Q8 (Execution, ordinal). Previously contained MMAS-8 approximations.
  • Patient Reference Code — Pharmacy setup screen now collects optional patient reference code (e.g. initials + birth year: MR1958). Stored as SITE_CODE + '_' + REF for repeat-visit longitudinal tracking without storing PII. Also collects age range and gender for SDoH fields in the assessments/ record.
  • TESSERA GRC Consortium Page — New standalone page at /consortium (public/consortium.html). Italy/Rome shown as TESSERA Hub I (founding site) with SVG map, TESSERA SITE 001 badge, 2026 Rome pilot timeline (20–30 pharmacies, 500 patients, 6 months), key partner profiles (Giuseppe Guaglianone / FOFI, Prof. Stefano Vella / ISS-Ministry), MAP domain explainer, and membership benefits. Links directly to pharmacy demo mode.
  • Italy as TESSERA Hub I on MAP Globe — A permanent gold marker at Rome (41.9028°N, 12.4964°E) is now always visible on the MAP mini-globe in the ATLAS PI dashboard, labelled "TESSERA Hub I — Rome". Visible regardless of whether real pharmacy data has been submitted. Real pharmacy submissions from PH-ROM-* site codes now include lat/lon and appear as standard green/amber/red dots on the same globe.
  • 3 institution tiers — Academic (INST-ACAD, $399/mo: Research Hub · Grants · Thesis), Health System (INST-HLTH, $599/mo: Care Gap Monitor · MTM Billing · Command Center), and AMC (INST-AMC, $799/mo: all features). Superadmin "View As" panel now shows three institution buttons.
  • 3 instruments — MMAS-8 (public screening), MAP (institutional cross-sectional, 8-item), PEACS (longitudinal 22-item: BASE / MVMT / STRATA)
  • Clinical Study Module — Site Activation Tracker and IRB Submission Assistant for funded PIs
  • Patient Portal — patients can view their own score history
  • ZOE Remote Mode — SMS-delivered independent assessment without clinic attendance
  • Multilingual UI — interface available in EN / ES / FR / DE / PT; consent, labels, and results all update automatically
  • Benchmark comparison — every result screen shows the published literature mean (Morisky et al., 2008) and current ATLAS global dataset mean alongside the patient's score
  • Annual State of Global Adherence Report — institution-tier aggregated population health publication
  • Cartographic design language — PE Triangle visualisation for Architecture · Execution · Context domain profiles
  • SDoH Intelligence System — Three automated inference engines pre-fill up to 22 PEACS questions from MAP responses, intake social support data, and OpenStreetMap geo-scoring (pharmacy/healthcare density from home postal code). Patient burden reduced by up to 60%.
  • Home Postal Code Field — Optional field in MAP intake form. Geocoded client-side via Nominatim; never stored to server. Enables geo-inference regardless of clinic vs. home setting.
  • Verified POI Network — Crowd-sourced infrastructure map. Authenticated users contribute pharmacies, hospitals, clinics, transport, food banks, and community centers. Two confirmations required for verification. Verified POIs appear on the SDoH Globe and feed PEACS geo-scoring.
  • Cinematic Globe — Now stays still unless a new assessment is submitted in real-time; globe flies to each new submission location as it arrives.
  • AIRC / LMIC Access Tier — Researchers at WHO/World Bank LMIC institutions can now apply for the ATLAS International Research Consortium program and receive free Researcher-tier access. Application is self-service through the Grant Resource Center. Approved members are automatically provisioned at login with no new key required.
  • LMIC Training Curriculum — Six-module structured curriculum on MAP/PEACS administration, interpretation, study design, and grant writing. Available in 10 languages (ES, PT, FR, HI, SW, ID, VI, TL, BN, AR). Accessible via the new Learning tab in the researcher dashboard rail.
  • LMIC Study Network and Grant Pipeline — Five pre-built study protocols (hypertension, HIV/ART, diabetes, TB, NCD normative) that auto-populate the study registry form. LMIC-filtered funding database. Fogarty D43 / R21 TW cover letter generator pre-filled from AIRC membership data.
  • Data-Lite / Bandwidth-Adaptive Mode — Automatic connection quality detection via the Network Information API and RTT probe. Activates a CSS lite-mode on 2G/slow connections, suppressing the globe, Mapbox maps, and Chart.js accordion. Manual toggle in the User Account panel. Responsive to network change events and browser data-saver flag.
  • Publication License Waiver for LMIC Researchers — AIRC members receive an automatic waiver recorded in the public registry at keys.adherence.cc. No flat-rate Publication License purchase required for data collected during active AIRC membership.
